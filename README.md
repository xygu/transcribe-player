# 扒谱播放器

一个纯前端的本地扒谱工具：区间循环、变速不变调、波形框选、10 段 EQ。
无需安装任何依赖，浏览器打开即用。

## 使用方法

1. 下载 `transcribe-player.html`，双击打开，点「打开音频文件」选择本地音频即可开始。
2. 想试听示例：把 `data/` 文件夹和 html 下载到同一目录，点页面上的「N95」按钮即可加载（示例为 30 秒片段）。

## 功能

- **播放控制**：播放/暂停、进度条、音量、±5 秒 / ±0.5 秒跳转
- **A-B 区间循环**：打点即循环；暂停后从播放头继续，仍在区间内循环；可临时关闭或清除
- **变速不变调**：0.3x–2.0x，对数刻度滑块（1x 居中），预设 0.3 / 0.5 / 0.75 / 1
- **波形图**：整轨波形 + 播放头 + 循环区间高亮；单击跳转，拖动直接框选循环区间
- **10 段图示 EQ**：31Hz–16kHz 倍频程分段，纵向推子，背景是 EQ 之后的实时频谱，拉动推子能立刻看到对应频段变化

## 快捷键

| 键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 5 秒 |
| Shift + ← / → | 0.5 秒微调 |
| ↑ / ↓ | 音量 |
| - / + | 速度微调（倍率步进） |
| 0 | 恢复原速 |
| A / B | 设 A 点 / B 点 |
| L | 循环开 / 关（保留点位） |
| X | 清除循环 |
| R | 回到 A 点 |

EQ 面板上：拖动推子调增益（±12dB），双击归零。
