# 扒谱播放器

一个纯前端的本地扒谱工具：区间循环、变速不变调、波形框选、10 段 EQ。
无需安装任何依赖，浏览器打开即用。

## 快速开始

**方式一：直接打开单文件版（可分享）**

双击 `transcribe-player.html`，点「打开音频文件」选择本地音频即可。
如果它和 `data/` 文件夹放在一起，还可以点「N95」一键加载示例音频。

**方式二：本地服务器（开发用）**

```bash
python3 server.py
```

然后打开 http://localhost:8765/player/

> 服务器自己实现了 HTTP Range 支持，拖进度条秒跳，不用等缓冲。

## 功能

- **播放控制**：播放/暂停、进度条、音量、±5 秒 / ±0.5 秒跳转
- **A-B 区间循环**：打点即循环；暂停后从播放头继续，仍在区间内循环；可临时关闭或清除
- **变速不变调**：0.3x–2.0x，对数刻度滑块（1x 居中），预设 0.3 / 0.5 / 0.75 / 1
- **波形图**：整轨波形 + 播放头 + 循环区间高亮；单击跳转，拖动直接框选循环区间
- **10 段图示 EQ**：31Hz–16kHz 倍频程分段，纵向推子，背景是 EQ 之后的实时频谱，拉动推子能立刻看到对应频段变化

## 快捷键

| 键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 5 秒 |
| Shift + ← / → | 0.5 秒微调 |
| ↑ / ↓ | 音量 |
| - / + | 速度微调（倍率步进） |
| 0 | 恢复原速 |
| A / B | 设 A 点 / B 点 |
| L | 循环开 / 关（保留点位） |
| X | 清除循环 |
| R | 回到 A 点 |

EQ 面板上：拖动推子调增益（±12dB），双击归零。

## 文件说明

- `player/` — 源代码（`index.html` / `style.css` / `app.js`）
- `player/build.py` — 打包脚本，运行后生成单文件版
- `transcribe-player.html` — 独立单文件版（所有 CSS/JS 已内联，可直接分享）
- `server.py` — 带 Range 支持的本地静态服务器
